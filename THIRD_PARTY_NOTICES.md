## Compiled files without SPDX tags

The build-specific source inventory reports 11 files without an SPDX tag;
this is not the same as 11 unknown licenses. Manual inspection found:

- `external/umac/src/main.c`, `scc.c`, and `via.c` contain Matt Evans's full
  MIT permission notice. `main.c` also credits small portions of Musashi code.
- `external/umac/external/Musashi/m68kcpu.c` and `m68kdasm.c` contain Karl
  Stenerud's full MIT permission notice. Generated `m68kops.c` comes from
  Musashi's `m68k_in.c`, which also contains that notice.
- `code_relocation.c`, `isr_tables.c`, and `misc/generated/configs.c` are
  generated by the Zephyr build; `misc/empty_file.c` is a zero-byte Zephyr
  placeholder. These files are not copied into the source repository.
- The linked `modules/fs/fatfs/ff.c` contains ChaN's FatFs R0.16
  redistribution conditions quoted in its own header. It is supplied by the
  Zephyr workspace rather than copied into this repository.

This classification covers the 11 missing-SPDX entries in the current
compiled-source inventory, not every file or notice in a future binary.
